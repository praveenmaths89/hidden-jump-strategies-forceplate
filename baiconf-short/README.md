# BAICONF 2026 short paper (IIMB Management Review, BAI2575)

"Revealing hidden jump strategies beyond conventional force-plate metrics": where along take-off and
landing countermovement-jump force curves differ, and what conventional force-plate metrics miss.

| Folder / file | Contents |
|---|---|
| `explore_fda/` | R analysis (functional regression, permutation tests, profiles, alignment, sampling audit), docs `METHODS_SPEC.md`, `SAMPLING_AUDIT.md`, `LITERATURE.md`, `FINDINGS.md`, all result tables (`tables/`) and diagnostic figures (`figs/`) |
| `paper/` | Overleaf project (manuscript, title page, exhibits, highlights); `numbers_fda.tex`, `tables/` and `figures/` are generated by `explore_fda/make_paper_outputs.R` |
| `build/` | Word versions: `python3 build_docx.py` (pandoc + python-docx) |
| `submission/` | Compiled PDFs and Word files, and the format-checker report |
| `IIMB_BAICONF2026_dataset.xlsx` | Trial-level data (pseudonymous IDs, age, body mass, sampling rate, vendor metrics, phase durations, QC flags, curve profiles) with a data dictionary. The 101-node force curves are not in the workbook; they are in `../iimb-baiconf-2026/data/cmj_trials_deidentified.csv`. |

## Reproduce

```
cd baiconf-short/explore_fda
Rscript run_all.R          # R 4.5, seed 2026; about 15-30 min; reads ../../iimb-baiconf-2026/data/cmj_trials_deidentified.csv
cd ../paper
latexmk                    # main, titlepage, highlights, exhibits
python3 check_format.py    # IIMB format checks
```

R packages: dplyr, tidyr, ggplot2, patchwork, refund, mgcv, cluster, mclust, diptest, fdasrvf, nlme, writexl
(see `explore_fda/sessionInfo.txt`). `CMJ_DATA=/path/to/file.csv` overrides the data location.

Raw force-time recordings are held by the testing centre under a non-disclosure agreement and are not in this repository.
