\noindent\textbf{Highlights}
\begin{itemize}
\item Equal jump heights concealed different force--time curves in 805 football jumps
\item Four curve components explained 74.8\% of variance, almost all in the landing
\item Vendor metrics, age and body mass explained only 2.7--13.1\% of each component
\item Curve-shape differences were largely trial-specific rather than athlete traits
\item Routine force-plate data contain unused information for monitoring decisions
\end{itemize}
